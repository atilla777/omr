# План реализации OMR

Общие требования: [SPEC.md](SPEC.md). Каждая нумерованная задача рассчитана
на отдельную сессию. Выполнять по порядку; уже завершённые задачи повторно не делать.

## Как продолжать в новой сессии

1. Прочитать `AGENTS.md`, `SPEC.md`, этот файл и результат предыдущих задач.
2. Найти первую незавершённую задачу и ограничить работу её объёмом.
3. При создании скила загрузить `ris-port-op-author-skill` через инструмент
   `skill`; при настройке OpenCode также загрузить доступный скил `opencode`
   и использовать документацию V2 (старые итоги ниже сохраняют исторические имена).
4. Сохранить файлы и выполнить соответствующие проверки. Если задача заблокирована,
   записать точный блокер и уже сделанное, оставив `[ ]`.
5. Только после выполнения критериев заменить `[ ]` на `[x]` и заполнить итог:
   пути к файлам, проверки, ограничения. Не начинать следующую задачу автоматически.
6. Не считать задачи завершёнными по одному наличию файлов. Не создавать ролики
   пользователя вместо проверки скила на небольшом примере.
