## Проверка обнаружения из demo

В `demo` нет собственного `.git`; проект остаётся в Git-дереве рабочей области.
Из `demo` запущены отдельные новые CLI-процессы:

```sh
opencode --version
script -q -e -c 'opencode debug skill' /dev/null
script -q -e -c 'opencode debug config' /dev/null
```

Псевдотерминал использован по документации OMR, чтобы избежать усечения
большого JSON. Оба диагностических вывода успешно разобраны как JSON.

- По одному экземпляру каждого из шести OMR/RIS-скилов обнаружено именно
  из `.opencode/skills/` целевой области, с непустым содержимым.
- Аналогично обнаружен установленный `remotion-best-practices`.
- Обнаружены пользовательские `manim` и `manim-local`, с непустым содержимым.
- Все шесть установленных команд имеют непустой шаблон с `$ARGUMENTS`.
- Существующая `owner-status` тоже обнаружена с непустым шаблоном.
- В `demo` и `missing` по-прежнему только исходные `brief.md`;
  корневой `node_modules` и Node-проект в `demo` не создавались.

Диагностика подтверждает обнаружение и чтение конфигурации, но не выполнение
команд агентом. Этапы OMR не вызывались; требования, контент, сценарий и видео
не создавались. Делегирования, подагентов, commit и push не было.
