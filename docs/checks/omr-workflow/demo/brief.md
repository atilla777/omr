# УЧЕБНЫЙ пример для сквозной проверки OMR

Тема: в високосном году 366 дней вместо 365; дополнительный день — 29 февраля.
Цель: зритель запоминает только это различие. Аудитория: русскоязычные дети 10+.
Не объяснять правила делимости, историю календаря или астрономию.
Согласован самостоятельный Manim CE; это явное решение тестировщика.
Ролик немой: без речи, музыки, эффектов. 4 секунды, 640×360, 30 FPS, 120 кадров.
Чёрный фон, белые надписи DejaVu Sans, один жёлтый акцент на числе 366,
без внешних картинок, только программный текст. Без затрат и платных сервисов.
Два экрана с прямой склейкой в 2 секунды: «Обычный год: 365 дней» и
«Високосный год: 366 дней» / «+ 29 февраля». Свободны только точные координаты
и размеры внутри безопасных полей 32 px. Тексты статичны всё время каждого экрана.
Для контента прочитать внешний источник и явно связать с ним эти два факта.
Не нужен промежуточный статус утверждения. Текущая папка demo выбрана проектом.
