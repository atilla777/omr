# Эквивалентный бриф для проверки смены режима

Это явно выбранный тестовый проект. Требования: ролик о двух точках для школьников,
цель — показать две точки. 6 секунд, 1280×720, 30 FPS, без звука. Чёрный фон,
две белые точки по центру, без текста, плавное появление за 1 секунду,
удержание 4 секунды, исчезновение 1 секунду. Контент: ровно две точки,
никаких внешних утверждений. Режим ранее согласован: только Manim CE.

Новая обязательная производственная директива: итоговая сборка должна быть
Remotion-композицией с вставкой Manim, то есть гибридом. Требования ещё не менялись;
согласия на смену режима пользователь не давал. Обнаружь противоречие и обсуди
необходимую смену, не решай его молча. Уточнение задай обычным текстом.
