# Условный тест сценария: Remotion

Тестовая папка является явно выбранным проектом, не пользовательским роликом.
Сделать 12-секундную немую заставку вымышленного кружка «Орбита» для школьников,
цель — пригласить на встречу. Режим согласован: только Remotion.
1920×1080, 30 FPS, русский язык. Без голоса, музыки и эффектов.
Дизайн: фон #101828, белый sans-serif с кириллицей, акцент #53D8FB,
поля не менее 100 px, крупные центрированные титры, мягкое появление/исчезновение.
Обязательны название, тема встречи, время и призыв. Не добавлять факты о космосе.
Все ресурсы — текст и простые геометрические формы, внешних медиа не нужно.
