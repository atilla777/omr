# Условный тест сценария: Manim

Эта папка — явно выбранный тестовый проект. Самостоятельный Manim CE,
12 секунд, 1280×720, 30 FPS. Русский язык, зрители — школьники, цель —
показать на точках равенство 2 + 3 = 5. Обязательны две группы, объединение
и итоговая формула; не вводить других математических фактов.
Фон #101828, белый sans-serif с кириллицей, первые две точки #53D8FB,
следующие три #FFCF56, безопасные поля 80 px. Формула сверху, точки ниже.
Голос: будущая запись пользователя на русском, взрослый спокойный голос;
текст готовится в сценарии, файл public/voice.wav будет записан на производстве
по интервалам сценария. Никакой TTS, музыки или эффектов. Длительность записи
пока не измерена; предусмотреть паузы. Внешние изображения не нужны.
