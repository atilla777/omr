# Условный тест сценария: гибрид

Эта папка — явно выбранный тестовый проект. Согласован гибрид: Manim создаёт
центральную вставку, Remotion — вступление, финал и сборку. 12 секунд,
1920×1080, 30 FPS. Школьники, русский язык, цель — показать 2 + 3 = 5.
Первые 3 секунды: титр «Сложение на точках» средствами Remotion.
Следующие 6 секунд: Manim показывает две и три точки, объединение в пять.
Последние 3 секунды: Remotion выводит «2 + 3 = 5» и «Считай вместе с нами».
Без озвучки, музыки и эффектов. Стиль: фон #101828 во всех частях, белый sans-serif
с кириллицей, точки #53D8FB и #FFCF56, поля 100 px. Вставка полноэкранная,
непрозрачная, без дополнительных титров Remotion поверх неё, без кроссфейдов
между частями; анимации затухания внутри выделенных интервалов.
Все ресурсы — геометрия и текст; внешние медиа не нужны.
