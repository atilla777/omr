# Тестовый бриф, не пользовательский ролик

Источник решений: этот бриф написан тестировщиком как ответы условного заказчика.
Все решения ниже заданы явно; неизвестен только выбор движка.

Тема — геометрический смысл равенства 1 + 2 + 3 = 6, цель — показать подсчёт
шести точек треугольником. Аудитория — школьники 10–12 лет, достаточно знания
сложения. Содержание: только расположение точек рядами 1, 2, 3 и итоговое равенство;
не нужны история, доказательство общей формулы или внешние факты.
Структурная свобода: порядок появления рядов и переходы определит сценарист.
Дизайн: тёмно-синий однотонный фон, белые точки, жёлтые числа, без персонажей.
Длительность 12 секунд, 1920×1080, 16:9, 30 FPS, MP4 для локального просмотра.
Экранный текст по-русски. Без озвучки, музыки и звуковых эффектов.
Все ресурсы — простые геометрические фигуры и текст, внешние медиа не нужны.
Бюджет нулевой, платные сервисы не использовать, других ограничений нет.
Режим не выбран: предложить подходящий и дождаться согласия.
