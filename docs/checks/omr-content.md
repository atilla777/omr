# Проверка `omr-content`

Дата: 16 октября 2026. OpenCode 1.18.33, CLI `opencode run`, штатный агент.
Технический условный пример задачи 4; пользовательский ролик не производился.
Исходники созданы после загрузки `ris-port-op-author-skill` и `customize-opencode`.

## Исходники и обнаружение

- `.opencode/skills/omr-content/SKILL.md`: имя соответствует папке, непустое
  описание содержит положительные и соседние случаи, лицензия MIT.
  Дополнительных ресурсов и обязательных скилов-зависимостей нет. Инструменты
  чтения файлов и веба используются по фактической доступности.
- `.opencode/commands/omr-content.md`: `description` и непустой шаблон с
  `$ARGUMENTS`; модель, агент и `subtask` не закреплены.
- Из временной `.omr-content-check/` без вложенного `.git` новые CLI-процессы
  обнаружили команду через `debug config` и ровно один скил с непустым телом
  через `debug skill` (6257 символов). JSON разобран и проверен Python assert;
  большой вывод скилов получен через `script -q -c 'opencode debug skill' /dev/null`.
- Просмотром инструкций проверены эквивалентный бриф, выбор проекта из корня,
  точечные изменения, конфликт источников, частичный результат, отказ записи,
  граница со сценарием, ручные переходы и отсутствие установки движков.
  Это структурная проверка, не наблюдаемое выполнение всех этих ветвей.

## Команда из подпапки: материалы и внешний поиск

Временный проект первоначально содержал только
[requirements.md](omr-content/requirements.md) и [notes.md](omr-content/notes.md).
Тема — правило високосных лет григорианского календаря для школьников 12–14 лет.

```sh
opencode run --format json --command omr-content 'Техническая проверка на условной теме. Собери материалы по requirements.md, используй notes.md и самостоятельно найди и прочитай внешние источники. Сохрани индекс и материалы, затем остановись.'
```

Сессия: `ses_ebbfc5fdaffeH2Ph3tmKxxK8N1`.
Наблюдались загрузка `skill(omr-content)`, чтение входов, самостоятельное открытие
<https://en.wikipedia.org/wiki/Leap_year>, поиск ссылки US Naval Observatory
в библиографии прочитанной страницы, запрос этой ссылки и тематической страницы
timeanddate.com. Отдельного инструмента поисковой выдачи в прогоне нет;
проверен поиск через энциклопедическую страницу и её ссылки.

US Naval Observatory завершился тайм-аутом; timeanddate.com вернул HTTP 403.
Первый CLI-вызов был остановлен лимитом оболочки 120 секунд. Проверка продолжена
в той же сессии с лимитом 240 секунд:

```sh
opencode run --format json --session ses_ebbfc5fdaffeH2Ph3tmKxxK8N1 'Продолжи прерванную техническую проверку с текущими источниками. Если первоисточник недоступен, используй прочитанные надёжные доступные материалы, явно укажи ограничения. Сохрани результат и перечитай файлы.'
```

Повторный запрос первоисточника был прерван. Агент сохранил и перечитал:

- [content/index.md](omr-content/content/index.md): назначение, входы, ссылка
  на материал, порядок чтения, покрытие требований и ограничения проверки;
- [content/leap-year.md](omr-content/content/leap-year.md): правило 4/100/400,
  причина поправки, примеры 1900/2000/2024/2100, расчёт 97 високосных лет за
  400 лет, оговорки и источники с датой обращения.

Результат независимо прочитан и сопоставлен с доступной страницей Wikipedia
через отдельный `webfetch`: правило, февраль, вековые примеры и приближения
365,2422/365,2425 соответствуют прочитанному разделу. Проверены арифметика
и локальные ссылки. Заметка пользователя не выдана за независимый источник.
Собственные расчёты отделены от фактов справочника. Материал содержит справочные
объяснения и таблицу, без сцен, тайминга и готовой озвучки. Требования не изменены.

Ограничение сохранено и в индексе, и в материале: прочитан один вторичный
источник, независимая сверка астрономического численного приближения не выполнена.
Недоступные страницы не перечислены как подтверждающие источники. Для проверки
скила этого небольшого примера достаточно; доступ к произвольным первоисточникам
и полнота поисковой выдачи этим не подтверждаются.

## Недостаточные требования

Из отдельной `.omr-content-missing-check/`, содержавшей только
[brief.md](omr-content/missing-brief.md):

```sh
opencode run --format json --command omr-content 'Прочитай brief.md и собери материалы. Если входов недостаточно, объясни пробел и предложи реализованную команду предыдущего этапа; уточнения задай обычным текстом.'
```

Сессия: `ses_ebbfc5fe3ffeC0cL0gZ0hZATw9`.
Агент загрузил только `omr-content`, прочитал бриф и проверил файл команды
`omr-requirements.md`. Объяснил, что без темы, цели и аудитории нельзя отобрать
факты и глубину, предложил `/omr-requirements`, запросил недостающие сведения.
Предыдущий этап не запускался, материалы не создавались. В папке остался только
исходный бриф. Уточнения были обычным текстом, не интерактивным `question`.

## Эффекты и границы проверки

- После выполнения в положительном проекте: только исходные `requirements.md`,
  `notes.md` и два Markdown-файла `content/`. В отрицательном — только `brief.md`.
  Не было package-файлов, движков, медиа, кода, сценария, рендеров или вложенного Git.
  В наблюдаемых действиях не было установки или вызовов других этапов.
- Исходные входы и результаты без изменения содержимого перенесены в
  `docs/checks/omr-content/`; относительные ссылки сохранились. Временные папки
  удалены. Проверены метаданные, ссылки, арифметика и `git diff --check`.
- Повторная точечная правка, эквивалентный бриф без `requirements.md`, запуск из
  корня, конфликт источников, полный отказ веб-доступа и отказ записи отдельными
  живыми прогонами не проверялись; соответствующие инструкции просмотрены.
- Движки и рендер к этому этапу не относятся и не проверялись. Текущая сессия
  не перечитывает новые скилы автоматически; загрузка подтверждена новыми
  CLI-процессами. Для использования команды нужно перезапустить OpenCode.
