# Условный тест производства: гибрид

Выбранная тестовая папка, цель — проверить стыковку Manim и Remotion.
Согласован гибрид: вставка Manim и финальная сборка Remotion. Для разработчика OMR.
4 с, 640×360, 30 FPS / 120 кадров. Фон #101820, белый Noto Sans,
акцент #66ddaa. Без речи/музыки/внешних ресурсов. В 3 с короткий локально
синтезированный тон 660 Hz на 0,2 с, пик 0,1 full scale, fade in/out 10 ms.
Зависимости Node локальные, точные версии. Общее Manim-окружение не менять.
