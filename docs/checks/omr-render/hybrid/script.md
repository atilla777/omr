# Стыковка

Основа: [требования](requirements.md), [материал](content/index.md).
Гибрид, 640×360, 30 FPS, 4 с / 120 кадров. Везде непрозрачный #101820.
Прямые склейки; звук только в финальной сборке.

- [0,30), 0–1 с: Remotion, белый «СТАРТ» 52 px по центру, неподвижно.
- [30,90), 1–3 с: Manim-вставка renders/insert.mp4, копия public/insert.mp4,
  H.264 без alpha и звука, 640×360, 30 FPS, ровно 60 кадров / 2 с.
  Локальные кадры [0,60) → глобальные [30,90), без растяжения/обрезки,
  объектный масштаб contain 1:1. Камера Manim frame_width 14,2222, height 8.
  Две точки радиуса 0,3, #66ddaa, в (-2,0),(2,0) видны уже с кадра 0;
  hold 0,5 с, за 1 с smooth сдвинуть в (-0,5,0),(0,5,0), hold 0,5 с.
  Без титров и аудио внутри вставки.
- [90,120), 3–4 с: Remotion, #66ddaa «ФИНИШ» 52 px по центру, hold.
  public/tone.wav из требований начинается точно на кадре 90.

Исходники src/manim/ и src/remotion/, итог out/video.mp4.
Просмотреть кадры 0,29,30,44,60,75,89,90,119 и проверить тон в 3–3,2 с.
