# Ресурсы

- `insert.mp4`: локальная генерация Manim CE, `src/manim/insert.py`,
  по предоставленному тестовому сценарию; непрозрачный H.264, без аудио.
  Оригинал — `renders/insert.mp4`. Команда воспроизведения — в `renders/verification.md`.
- `tone.wav`: локальный синтез `python src/prepare.py`, PCM S16 mono 48000 Hz,
  9600 samples / 0,2 с, sinus 660 Hz, peak 0,1 full scale, линейные fade
  in/out по 480 samples / 10 ms. Нет внешнего автора или лицензируемой записи.
- Шрифт: установленный Noto Sans Regular, `/usr/share/fonts/noto/NotoSans-Regular.ttf`,
  Noto Project, SIL Open Font License 1.1; используется системным Chromium,
  файл шрифта в проект не копируется.

Внешние изображения, видео, музыка и речь не используются.
