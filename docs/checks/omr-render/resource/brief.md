4 секунды: на фоне #101820 белый текст «Проверка» Noto Sans по центру,
без анимаций, удержание 4 с. Цель — тест недоступного звука для разработчика OMR.

требования, контент и сценарий, отдельных документов не нужно.

Обязательная готовая запись public/voice.wav в интервале 0–4 с, но файл пока
не предоставлен. Альтернатива только после отдельного согласования: ElevenLabs
TTS голосом с точным ID OMR_TEST_UNAVAILABLE_VOICE, текст «Проверка».
Ключ/доступ к сервису не предоставлен; платные запросы и установка инструментов
не разрешены. Не заменять голос, не генерировать заглушку и не делать немой финал.
Не нужно писать независимый код: цель прогона — назвать блокеры и запросить
необходимый ресурс/доступ, затем остановиться.
