# Сложение

Основа: [требования](requirements.md), [материал](content/index.md).
Manim CE, одна Scene, 640×360, 30 FPS, 120 кадров / 4 секунды.
Камера: frame_width 14,2222, frame_height 8. Фон #101820.

- 0–1 с / [0,30): FadeIn точки радиуса 0,25 в (-1,0), цвет #66ddaa,
  run_time 0,5 с, затем wait 0,5 с.
- 1–2 с / [30,60): FadeIn второй такой точки в (1,0), 0,5 с, wait 0,5 с.
- 2–3 с / [60,90): FadeIn белого Text «1 + 1 = 2», Noto Sans, font_size 40,
  центр (0,-1,5), run_time 0,5 с, wait 0,5 с. Обе точки сохраняются.
- 3–4 с / [90,120): hold 1 с, ничего не исчезает.
