# Условный тест производства: Manim

Выбранная тестовая папка; цель — показать 1+1=2 разработчику OMR.
Согласован чистый Manim CE без Remotion и Node. 4 секунды, 640×360,
30 FPS / 120 кадров, фон #101820, белые надписи Noto Sans, точки #66ddaa.
Без речи, музыки, эффектов и внешних ресурсов. Использовать доступное uv tool
окружение без его изменения; для формулы допустим Text, TeX не требуется.
