# Две карточки

Основа: [требования](requirements.md), [материал](content/index.md).
Remotion, 640×360, 30 FPS, 4 с / 120 кадров, без перекрытий.

- [0,60), 0–2 с: «OMR» по центру, 64 px, белый; fade 0→1 на кадрах 0–9,
  далее удержание. Фон #101820.
- [60,120), 2–4 с: прямая склейка; «ГОТОВО» по центру, 52 px, #66ddaa;
  fade 0→1 на локальных кадрах 0–9, затем удержание до конца.
- Короткий тон из требований ровно в 2–2,2 с. Другого звука нет.

Создать public/tone.wav локальным синтезом. Исходники src/remotion/,
итог out/video.mp4. Проверить кадры 0,9,59,60,65,69,119, начало звука и тишину.
