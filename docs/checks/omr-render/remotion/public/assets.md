# Ресурсы

- `tone.wav`: локальный процедурный синтез Python, без внешних ресурсов.
  Синус 660 Hz, 0,2 с, моно PCM signed 16-bit, 48000 Hz, пик 0,1 full scale,
  линейные fade-in/out по 10 ms. Автор — производственный этап этого теста.
  Повторное создание: `python renders/synthesize.py` из папки проекта.
- Шрифт: системный Noto Sans Regular (`fc-match 'Noto Sans'`),
  `/usr/share/fonts/noto/NotoSans-Regular.ttf`, семейство Noto, SIL OFL 1.1.
  Шрифт не копируется и не скачивается; используется установленный пакет ОС.
