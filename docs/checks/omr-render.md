Дата: 16 октября 2026. Задача 6. OpenCode CLI 1.18.33, новые процессы из
отдельных выбранных тестовых подпапок общего Git-дерева, без вложенного `.git`.
Это условные четырёхсекундные примеры, не персональные ролики пользователя.

## Исходники и подключение

- Созданы после загрузки `ris-port-op-author-skill` и `customize-opencode`:
  `.opencode/skills/omr-render/SKILL.md`, `.opencode/commands/omr-render.md`.
  Локальное подключение — размещение в штатных каталогах по поручению задачи.
- Скил владеет полным производством, подготовкой окружений/медиа и проверкой
  `out/video.mp4`. Обязательная загрузка технических зависимостей, три режима,
  ресурсы/голос/доступы, частичный результат и остановка описаны явно.
- Из `omr-render/remotion/` `opencode debug config` распознал команду с непустым
  `description`, шаблоном и `$ARGUMENTS`, без закреплённых модели/агента/subtask.
  `script -q -c 'opencode debug skill' ...` обнаружил ровно один `omr-render`
  с непустым телом 9562 символа. JSON разобран с учётом заголовка утилиты `script`.
- Через `skill` в текущей сессии загружены `remotion-best-practices`, `manim`,
  `manim-local`; технические зависимости повторно реально загрузились в CLI-прогонах.
  Внешние скилы не объявлены частью MIT OMR; дополнительных ресурсов скилу не нужно.

## Реальное производство

Запуск из каждой соответствующей папки:

```sh
opencode run --format json --command omr-render '<задание проверки>'
```

Задание: папка явно выбрана тестовым проектом; выполнить производство по
`requirements.md`, `content/index.md`, `script.md` до `out/video.mp4`, извлечь
и просмотреть реальные кадры, проверить предусмотренный звук/его отсутствие,
сохранить команды и ограничения в `renders/verification.md`; не менять входы,
не делегировать. Для Remotion/гибрида разрешена локальная установка Node-пакетов;
для Manim — имеющееся uv tool окружение без изменения. Для автоматического теста
явно запрещён запуск Studio/GUI/desktop-плееров; просмотр — PNG, звук — измерения.
Это условие тестировщика, не ограничение возможностей самого скила.

### Звук

Manim — один видеопоток, аудиопотоков нет. В двух остальных примерах локальный
генератор создал заданный синус 660 Hz / 0,2 с с fade 10 ms; сохранены команды
и реестры ресурсов. В итоговых MP4 — AAC stereo 48 kHz. По декодированным отсчётам
измерены частота, пики, тишина и привязка сигнала к переходам.

Независимая проверка родительской сессией по одному каналу (без усиливающего downmix):

| Пример | Пик FS | Интервал выше 0,001 FS | Сценарный интервал |
|---|---|---|---|
| Remotion | 0,100415 | 2,000167–2,199875 с | 2–2,2 с |
| Гибрид | 0,100780 | 3,000167–3,199854 с | 3–3,2 с |

Клиппинга нет; до/после события сигнал ниже порога с учётом слабого AAC-предэха/
хвоста. Контейнеры со звуком — 4,011 с из-за AAC-пакетов, видеоряд строго 4 с.
В CLI исправлены способ аудиоизмерения (downmix добавлял +3 dB) и параметр bundle
(`--out-dir`, а не позиционный путь). Это технические исправления без смены сценария.

**Прослушивания и воспроизведения в реальном времени не было.** Звук проверен
численно, движение — последовательностью PNG и измерением положений. Проверка
разборчивости речи не заявляется: речи в положительных примерах нет.

## Ресурсы: фактическая доступность

Помимо локального синтеза тона и программной графики Manim выполнен небольшой
прямой probe инструментов родительской сессией, отдельно от немедийных сценариев:

1. Webfetch страницы `https://images.nasa.gov/details/PIA00405` вернул только
   требование JavaScript. Одна доступная URL не означает прочитанную карточку.
2. Webfetch [NASA Image API](https://images-api.nasa.gov/search?nasa_id=PIA00405)
   реально вернул запись Earth Moon, автора NASA/JPL/USGS и прямые ссылки.
   Проверен поиск по ID в каталоге, не универсальная поисковая выдача.
3. `curl --fail --location --max-time 30` скачал
   [JPEG](https://images-assets.nasa.gov/image/PIA00405/PIA00405~thumb.jpg)
   в `/tmp/opencode/omr-render-nasa.jpg`: 62763 байта, MJPEG/JPEG 640×640 по ffprobe.
   Файл открыт через `read`: реальное изображение Луны, не HTML/ошибка.
4. Прочитаны [условия NASA](https://www.nasa.gov/nasa-brand-center/images-and-media/):
   информационное использование допускается с соблюдением правил и указанием
   источника, сторонние материалы/логотипы имеют отдельные ограничения.
   Изображение не включено в ролики/репозиторий и не объявлено MIT OMR.

Поиск/скачивание внешнего видео, музыки и эффектов, готовая речь, TTS, сервисная
генерация изображений/видео не прогонялись. Доступный TTS/генератор не заявляется;
инструкции скила требуют проверки инструмента и согласования недостающих доступов.

## Сохранение и ограничения

Сохранены входы, исходники, точные манифесты/lock-файлы, генераторы, проверочные
скрипты, реестры, небольшие контактные листы, измерения и отчёты. Полные трассы
доступны локально в хранилище OpenCode по ID сессий; JSONL — временно в
`/tmp/opencode/omr-render-*.jsonl`. MP4, WAV, отдельные PNG и кэши оставлены локально
и исключены через `.gitignore`; команды воспроизведения находятся в отчётах.

Проверены метаданные, локальные ссылки, Python-синтаксис и diff. Персональные пути
есть только как факты окружения в свидетельствах, не в переносимом скиле/исходниках.
Проверка из корня с выбором папки, точечная повторная правка, отказ записи, потеря
движка/технического скила, прозрачные вставки и существенная смена режима оценены
просмотром инструкций, не отдельными живыми прогонами. TeX/Typst не компилировались.
