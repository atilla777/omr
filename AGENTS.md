# Работа в этой папке

## Структура проектов

- Эта папка — рабочая область для проектов Remotion.
- Создавай каждый новый проект Remotion в отдельной подпапке этой папки.
- Файлы, зависимости и ресурсы каждого проекта размещай в его подпапке; команды установки, разработки и рендеринга выполняй из папки соответствующего проекта.

## Скилы

- При создании, изменении, отладке и рендеринге проектов Remotion обязательно используй доступные Remotion-скилы: загружай подходящие скилы до начала работы и следуй их инструкциям.
- Если необходимые Remotion-скилы недоступны, сообщи об этом пользователю и согласуй их установку.
- Локальные скилы OpenCode для этой рабочей области находятся в `.opencode/skills/`.
